Floci: AWS di Laptop Anda

Floci adalah emulator AWS lokal yang gratis dan open-source. Ia meniru 130+ layanan AWS (S3, SQS, DynamoDB, Lambda, IAM, dan lainnya) di satu port, http://localhost:4566, sehingga Anda bisa mengembangkan dan menguji aplikasi tanpa akun AWS, tanpa biaya, dan tanpa internet.

Penjelasan sederhana

Bayangkan AWS sebagai sebuah mal besar dengan ratusan toko (S3 = gudang file, SQS = kotak surat antrean, DynamoDB = lemari arsip, Lambda = tukang yang dipanggil saat dibutuhkan). Kalau mau latihan berjualan di mal sungguhan, Anda harus menyewa tempat dan membayar.

Floci adalah replika mal itu di rumah Anda. Bentuk pintu, formulir, dan cara bicaranya persis sama, jadi aplikasi Anda tidak bisa membedakan apakah ia sedang bicara ke AWS asli atau ke Floci. Bedanya, semuanya berjalan di komputer Anda sendiri dan gratis.

Floci dalam satu paragraf (versi teknis)

Floci adalah aplikasi Java 25 di atas framework Quarkus 3.40. Semua permintaan HTTP masuk ke port 4566, melewati rangkaian filter JAX-RS (penentuan akun, klaim protokol, verifikasi tanda tangan opsional, penegakan IAM opsional), lalu di-dispatch ke controller sesuai protokol AWS-nya. Controller memanggil service berisi logika bisnis, yang menyimpan state lewat StorageFactory (memory/persistent/hybrid/WAL) dengan namespace per akun. Layanan "berat" seperti Lambda, RDS, ElastiCache, ECS, EKS, dan OpenSearch menjalankan container Docker sungguhan. Tujuan utamanya adalah kompatibilitas wire-protocol: AWS SDK, CLI, Terraform, dan CDK bekerja tanpa diubah.
