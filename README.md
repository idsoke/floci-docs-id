# Dokumentasi Floci (Bahasa Indonesia)

Dokumentasi tidak resmi untuk [Floci](https://github.com/floci-io/floci), emulator AWS open-source yang berjalan di laptop, ditambah kursus praktik **Belajar AWS dari Nol** untuk pemula.

**Baca online:** https://idsoke.github.io/floci-docs-id/

## Isi

- **Belajar AWS dari Nol**: 8 modul praktik (S3, SQS, SNS, DynamoDB, Lambda, IAM, proyek akhir) dengan latihan, kunci jawaban, kuis, dan checklist progres.
- **Cara Kerja**: arsitektur Floci, alur request, protokol AWS, penyimpanan, akun dan IAM, siklus hidup, Lambda, alur event, lengkap dengan diagram animasi.
- **Referensi**: katalog 137 layanan, konfigurasi dan port, panduan kontributor, glosarium.

Situs ini statis (HTML, CSS, JavaScript tanpa library) dan bisa dibuka langsung dari file `index.html`.

## Catatan

- Proyek ini tidak berafiliasi dengan tim Floci maupun Amazon Web Services.
- Disusun dari kode sumber dan dokumentasi Floci versi 2.4.0, dibantu AI.
- Perintah di modul belajar belum seluruhnya diuji. Jika menemukan kesalahan, silakan buka issue.
