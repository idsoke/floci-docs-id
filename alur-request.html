Alur Request: Perjalanan Satu Panggilan API

Halaman ini mengikuti satu request dari SDK sampai jawaban kembali, termasuk setiap filter yang dilewati, dalam urutan yang sama dengan kode sumber.

Penjelasan sederhana

Setiap request seperti paket kiriman yang masuk ke gudang sortir:

1️⃣ Petugas pertama membetulkan label alamat (mis. URL antrean SQS diubah ke format standar).
2️⃣ Petugas kedua membaca stempel pengirim untuk tahu paket ini milik akun mana.
3️⃣ Petugas ketiga mengenali jenis paket (protokol) dan layanan tujuannya.
4️⃣ Bagian keamanan memeriksa tanda tangan dan izin (kalau fitur ini dinyalakan).
5️⃣ Paket diantar ke loket layanan yang tepat, dikerjakan, dan balasannya diberi nomor resi (request-id) sebelum dikirim balik.

Animasi lengkap: SQS SendMessage

Contoh: aws sqs send-message --queue-url http://localhost:4566/000000000000/orders --message-body "halo" dengan AWS CLI modern (protokol JSON 1.0).

Urutan filter (dari kode sumber)

JAX-RS menjalankan filter berdasarkan anotasi @Priority: angka lebih kecil berjalan lebih dulu. Filter pre-matching berjalan sebelum JAX-RS memilih controller, sehingga boleh mengubah path. Filter biasa berjalan setelah controller terpilih.

A. Filter pre-matching (sebelum routing)

PrioritasFilterApa yang dikerjakan
1MissingHostHeaderFilterMemberi header Host pada request HTTP/1.0 yang tidak membawanya, agar filter berikutnya tidak gagal.
5LambdaUrlRoutingFilterMengenali host Function URL Lambda (<id>.lambda-url...) dan mengarahkannya ke invocation.
9–15ApiGatewayExecuteApiHostFilter, ApiGatewayCustomDomainFilter, CognitoCustomDomainFilter, CloudFrontDistributionFilterRouting berdasarkan hostname untuk API Gateway (execute-api), domain kustom, Cognito, dan CloudFront.
900AccountContextFilterMembaca access key dari Authorization (atau X-Amz-Credential untuk presigned URL), menentukan account ID dan region, lalu mengisi RequestContext.
3000AwsCborContentTypeFilter, GlobalCorsFilterMenyimpan content-type CBOR asli; menjawab preflight CORS dari browser.
5000 (default)SqsQueueUrlRouterFilter, S3VirtualHostFilter, EmrServerlessRouteFilter, DlmRouteFilter, …Menulis ulang path: URL antrean /{akun}/{antrean} → POST /; host bucket.s3.localhost... → path-style /bucket/key.
6000AwsProtocolClaimFilterMemanggil ProtocolClaimer untuk mengenali protokol (rpcv2 CBOR/JSON, JSON 1.0, JSON 1.1, Query, REST). Menolak request REST bertanda tangan untuk layanan yang tidak dikenal.

B. Filter setelah routing

PrioritasFilterApa yang dikerjakan
800AwsRouteClaimFilterKalau request belum diklaim (mode non-strict), klaim berdasarkan route yang dicapai.
1000SigV4HeaderSignatureFilter, S3HeaderSignatureFilter, PreSignedUrlFilterVerifikasi tanda tangan SigV4 (hanya bila FLOCI_AUTH_VALIDATE_SIGNATURES=true atau IAM enforcement aktif) dan presigned URL S3.
3100AwsRestRouteScopeFilterMemastikan scope tanda tangan cocok dengan layanan REST yang dituju.
5000 (default)ServiceEnabledFilterMenentukan layanan dari klaim / kelas resource / scope SigV4, lalu menolak bila layanan dimatikan (floci.services.<x>.enabled=false).
5000 (default)IamEnforcementFilterBila FLOCI_SERVICES_IAM_ENFORCEMENT_ENABLED=true: autentikasi kredensial, lalu evaluasi kebijakan identitas, resource policy, SCP, session policy, permission boundary, dan kondisi.

C. Filter respons

FilterApa yang dikerjakan
AwsRequestIdFilterMenambah x-amz-request-id (REST/Query), x-amzn-RequestId (JSON), x-amz-id-2 (S3).
AwsDateHeaderFilterMenambah header Date seperti AWS.
AwsRestJsonErrorHeaderFilterMenambah x-amzn-ErrorType untuk error REST JSON.
S3CorsFilter, S3ContentTypeCharsetFilterHeader CORS per-bucket dan content-type khusus S3.

Animasi: request yang ditolak

Dua jalur gagal yang paling umum: layanan dimatikan, dan IAM enforcement menolak.

Thread dan konkurensi

  • Request biasa dilayani oleh worker Quarkus/Vert.x.
  • Dispatcher JSON 1.0, CBOR, dan Query berjalan di virtual thread Java, sehingga long-polling (ReceiveMessage SQS hingga 20 detik, GetActivityTask Step Functions hingga 60 detik) tidak memblokir worker bersama.
  • Pekerjaan latar (poller ESM, sweeper TTL, flush storage) memakai timer Vert.x dan primitif seperti KeyedWorkQueue dan VersionedSignal (lihat docs/concurrency.md).
