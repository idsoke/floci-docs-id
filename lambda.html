Lambda: Fungsi di Container Sungguhan

Floci menjalankan kode Lambda Anda di dalam container Docker yang memakai image runtime resmi AWS (public.ecr.aws/lambda/...). Container itu berbicara ke Runtime API yang disediakan Floci, persis seperti di AWS.

Penjelasan sederhana

Lambda seperti tukang panggilan. Saat ada pekerjaan, Floci "memanggil tukang" (menyalakan container), memberinya tugas (event), menunggu hasilnya, lalu mengirim hasil ke pemesan. Supaya tidak lambat, tukang yang baru selesai disuruh menunggu sebentar di pos (warm pool). Kalau ada pekerjaan baru untuk fungsi yang sama, tukang yang sedang menunggu itu langsung dipakai (warm start) tanpa harus dipanggil dari rumah (cold start).

  • Poller memakai timer Vert.x (non-blocking), interval default FLOCI_SERVICES_LAMBDA_POLL_INTERVAL_MS=1000.

Invocation asinkron

InvocationType: Event langsung dijawab 202, lalu dijalankan di pool latar. Jika gagal, dicoba ulang hingga MaximumRetryAttempts (default 2, total 3 percobaan) selama umur event belum melewati MaximumEventAgeInSeconds (default 6 jam). Retry pertama menunggu 1 menit, kedua 2 menit (atur dengan FLOCI_SERVICES_LAMBDA_ASYNC_RETRY_DELAY_SECONDS, 0 untuk tes cepat). Setelah habis, event dikirim ke destination on-failure atau DLQ.

Hot reload untuk pengembangan

📁 Bind mount

Buat fungsi dengan --code S3Bucket=hot-reload,S3Key=/path/absolut/kode. Folder di host di-mount langsung ke container. Simpan file → invoke berikutnya memakai kode baru. Perlu FLOCI_SERVICES_LAMBDA_HOT_RELOAD_ENABLED=true dan ..._ALLOWED_PATHS.

🔁 Reactive S3 Sync

Jika fungsi di-deploy dari objek S3, menimpa objek tersebut otomatis men-deploy ulang fungsi dan membuang container warm yang lama. Aktif secara default.

Wajib: Lambda dengan executor Docker butuh socket Docker: -v /var/run/docker.sock:/var/run/docker.sock.

Contoh lengkap

# handler.py
def handler(event, context):
    return {"pesan": f"Halo, {event.get('nama', 'dunia')}!"}

zip fn.zip handler.py
aws lambda create-function --function-name halo \
  --runtime python3.12 --handler handler.handler \
  --role arn:aws:iam::000000000000:role/lambda-role \
  --zip-file fileb://fn.zip
aws lambda invoke --function-name halo \
  --cli-binary-format raw-in-base64-out \
  --payload '{"nama":"Idris"}' out.json && cat out.json
# {"pesan": "Halo, Idris!"}
