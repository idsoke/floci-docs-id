Belajar AWS dari Nol dengan Floci

Kursus praktik untuk Anda yang belum pernah memakai AWS sama sekali. Semua latihan dijalankan di laptop memakai Floci: tanpa akun AWS, tanpa kartu kredit, tanpa risiko tagihan.

Penjelasan sederhana

AWS itu seperti mal raksasa yang menyewakan "alat": gudang file (S3), kotak surat (SQS), pengeras suara (SNS), lemari arsip super cepat (DynamoDB), tukang yang datang hanya saat dipanggil (Lambda), dan satpam yang mengecek kartu akses (IAM). Anda membayar per pemakaian.

Floci adalah miniatur mal itu di laptop Anda. Pintu masuk, loket, dan aturannya meniru aslinya, sehingga cara Anda "berbelanja" (perintah AWS CLI, kode SDK, Terraform) persis sama. Bedanya: gratis, dan kalau berantakan tinggal dihapus lalu mulai lagi dalam hitungan detik.

Progres Anda

Centang Selesai di setiap langkah modul. Progres disimpan di browser ini saja.

Kenapa urutannya begini?

1️⃣

Mulai dari yang terlihat

S3 paling mudah dibayangkan: file masuk, file keluar. Cocok untuk membiasakan diri dengan AWS CLI.

2️⃣

Lalu cara layanan "mengobrol"

SQS dan SNS mengajarkan pola pesan, yang menjadi perekat hampir semua aplikasi AWS.

3️⃣

Menyimpan data & menjalankan kode

DynamoDB (data) dan Lambda (kode) melengkapi "batu bata" aplikasi serverless.

4️⃣

Keamanan, lalu merangkai semuanya

IAM paling masuk akal setelah Anda tahu layanan apa yang ingin dilindungi. Proyek akhir menggabungkan semuanya.

Apa yang tidak bisa dipelajari di Floci

Floci meniru API AWS, bukan seluruh pengalaman AWS. Hal-hal berikut perlu dipelajari dari materi resmi atau akun AWS sungguhan:

  • AWS Management Console (tampilan web resmi AWS). Floci punya konsol sendiri di http://localhost:4566/_floci/ui, tetapi tampilannya berbeda.
  • Tagihan dan biaya: cara harga dihitung, Free Tier, dan budget alert.
  • Jaringan sungguhan: VPC, subnet, latensi antar-region, dan performa skala besar.
  • Batas (quota) dan perilaku tepat di beberapa kasus tepi. Selalu uji ulang di AWS sebelum produksi.

Langkah setelah kursus ini: sertifikasi AWS Certified Cloud Practitioner (dasar), lalu Developer – Associate atau Solutions Architect – Associate. Materi modul 1–7 di sini adalah inti dari keduanya. Kalau mulai memakai akun AWS sungguhan, pasang budget alert lebih dulu dan hapus resource setiap selesai latihan.

Cara memakai kursus ini

  1. Buka satu modul, baca Penjelasan sederhana dan tonton animasinya (tombol ▶ Putar).
  2. Kerjakan setiap langkah praktik di terminal. Tombol Salin ada di setiap blok perintah.
  3. Bandingkan output Anda dengan kotak Hasil yang diharapkan. ID, tanggal, dan hash akan berbeda; itu normal.
  4. Centang Selesai, kerjakan Latihan mandiri tanpa melihat kunci, lalu jawab Kuis.
  5. Kalau error, lihat bagian Kesalahan umum di modul tersebut.
