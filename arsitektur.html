Arsitektur Floci

Floci adalah satu aplikasi Java (Quarkus) yang berisi lebih dari 130 layanan AWS. Setiap layanan mengikuti pola berlapis yang sama, dan semuanya berbagi infrastruktur inti.

Penjelasan sederhana

Bayangkan sebuah kantor pelayanan publik:

🚪 Satpam & resepsionis (filter) memeriksa tamu: dari akun mana, bahasanya apa, boleh masuk atau tidak.
🧾 Petugas loket (controller/handler) membaca formulir dan menyerahkannya ke bagian yang tepat.
👩‍💼 Staf ahli (service) mengerjakan permintaannya sesuai aturan.
🗄️ Ruang arsip (storage) menyimpan semua dokumen, dipisah per akun.
Setiap "bagian" (S3, SQS, Lambda, dll.) punya loket dan staf ahli sendiri, tapi satpam, resepsionis, dan ruang arsipnya dipakai bersama.

Lapisan arsitektur (animasi)

Peran tiap lapisan

1. Filter JAX-RS

Berjalan sebelum controller. Menentukan akun & region (AccountContextFilter), mengenali protokol (AwsProtocolClaimFilter), memeriksa layanan aktif (ServiceEnabledFilter), memverifikasi tanda tangan (SigV4HeaderSignatureFilter, opsional), dan menegakkan IAM (IamEnforcementFilter, opsional).

2. Controller / Handler

Mem-parsing input protokol AWS dan menghasilkan respons berformat AWS. Dibuat tipis: tidak berisi logika bisnis. Namanya mengikuti protokol: *Controller (REST), *QueryHandler (Query), *JsonHandler (JSON 1.1).

3. Service

Logika bisnis layanan, mis. SqsService, S3Service, LambdaService. Kesalahan domain dilempar sebagai AwsException dengan kode error AWS.

4. Model & Storage

Objek domain di model/. State disimpan lewat StorageFactory, yang membuat StorageBackend sesuai mode dan membungkusnya dengan namespace akun.

Dependency injection (CDI)

Semua komponen adalah bean CDI (@ApplicationScoped) yang disuntikkan lewat konstruktor @Inject. Contoh: AwsJson11Controller menerima puluhan handler di konstruktornya, lalu memilih salah satu dengan switch (serviceKey). Pola konstruktor ini juga memudahkan tes: konstruktor package-private dipakai untuk menyuntikkan objek tiruan.

// Potongan nyata dari AwsJson11Controller.handle(...)
Response delegated = switch (serviceKey) {
    case "ssm"            -> ssmJsonHandler.handle(action, request, region, authorization);
    case "events"         -> eventBridgeHandler.handle(action, request, region);
    case "logs"           -> cloudWatchLogsHandler.handle(action, request, region);
    case "kms"            -> kmsJsonHandler.handle(action, request, region);
    case "secretsmanager" -> secretsManagerJsonHandler.handle(action, request, region, authorization);
    // ... puluhan layanan lain
    default -> null;   // → UnknownOperationException
};

Komponen di luar proses Floci

Untuk layanan berbasis container, Floci berperan sebagai pengatur: ia memanggil Docker API untuk membuat container, lalu menyediakan proxy TCP (RDS, ElastiCache, MemoryDB, Neptune) atau membiarkan Docker mem-bind port langsung (EKS, OpenSearch, Amazon MQ, konsol web).
