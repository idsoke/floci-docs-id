Cara Memakai Floci

Dari menyalakan Floci sampai menyambungkan AWS CLI, SDK, Terraform, dan tes otomatis.

Intinya hanya 2 langkah

1️⃣ Nyalakan Floci (Docker atau binary).
2️⃣ Arahkan alat AWS Anda ke http://localhost:4566 dengan kredensial palsu (test/test).
Selebihnya, pakai perintah dan kode AWS seperti biasa.

Animasi: dari nol sampai bucket pertama

1. Menyalakan Floci

Belum memasang Docker? Ikuti dulu Menjalankan di Laptop (Windows, macOS, Linux, Compose, menyimpan data, dan solusi masalah).

floci start          # menyalakan emulator
eval $(floci env)    # mengekspor variabel AWS_* untuk shell ini
floci stop

CLI resmi ada di repo floci-io/floci-cli.

# compose.yaml
services:
  floci:
    image: floci/floci:latest
    ports:
      - "4566:4566"
    volumes:
      - /var/run/docker.sock:/var/run/docker.sock   # hanya jika butuh Lambda/RDS/dll.

docker compose up -d
docker run --rm -p 127.0.0.1:4566:4566 \
  -v /var/run/docker.sock:/var/run/docker.sock \
  floci/floci:latest

Setiap rilis menyertakan binary floci-aws untuk Linux, macOS, dan Windows (tanpa Docker). Layanan berbasis container tetap butuh Docker.

./floci-aws
# di Windows: floci-aws.exe
git clone https://github.com/floci-io/floci.git
cd floci
./mvnw quarkus:dev          # mode dev dengan live reload (butuh JDK 25)

2. Mengatur kredensial dan endpoint

export AWS_ENDPOINT_URL=http://localhost:4566
export AWS_DEFAULT_REGION=us-east-1
export AWS_ACCESS_KEY_ID=test
export AWS_SECRET_ACCESS_KEY=test
$env:AWS_ENDPOINT_URL="http://localhost:4566"
$env:AWS_DEFAULT_REGION="us-east-1"
$env:AWS_ACCESS_KEY_ID="test"
$env:AWS_SECRET_ACCESS_KEY="test"
# ~/.aws/config
[profile floci]
region = us-east-1
endpoint_url = http://localhost:4566

# ~/.aws/credentials
[floci]
aws_access_key_id = test
aws_secret_access_key = test

aws --profile floci s3 ls

Tips: SDK modern membaca AWS_ENDPOINT_URL otomatis, jadi kode aplikasi tidak perlu diubah sama sekali. Region apa pun yang dipublikasikan AWS bisa dipakai, termasuk ap-southeast-3 (Jakarta).

4. Dari kode (SDK)

import boto3
s3 = boto3.client("s3", endpoint_url="http://localhost:4566",
                  region_name="us-east-1",
                  aws_access_key_id="test", aws_secret_access_key="test")
s3.create_bucket(Bucket="laporan")
s3.put_object(Bucket="laporan", Key="a.txt", Body=b"halo")
print(s3.list_objects_v2(Bucket="laporan")["KeyCount"])
S3Client s3 = S3Client.builder()
    .endpointOverride(URI.create("http://localhost:4566"))
    .region(Region.US_EAST_1)
    .credentialsProvider(StaticCredentialsProvider.create(
        AwsBasicCredentials.create("test", "test")))
    .forcePathStyle(true)
    .build();
s3.createBucket(b -> b.bucket("laporan"));
import { S3Client, CreateBucketCommand } from "@aws-sdk/client-s3";
const s3 = new S3Client({
  endpoint: "http://localhost:4566", region: "us-east-1", forcePathStyle: true,
  credentials: { accessKeyId: "test", secretAccessKey: "test" },
});
await s3.send(new CreateBucketCommand({ Bucket: "laporan" }));
cfg, _ := config.LoadDefaultConfig(ctx,
    config.WithRegion("us-east-1"),
    config.WithBaseEndpoint("http://localhost:4566"),
    config.WithCredentialsProvider(credentials.NewStaticCredentialsProvider("test", "test", "")))
client := s3.NewFromConfig(cfg, func(o *s3.Options) { o.UsePathStyle = true })

S3 path-style: aktifkan forcePathStyle / s3_use_path_style, atau gunakan hostname virtual-host bucket.s3.localhost.floci.io:4566 yang dikenali S3VirtualHostFilter.

5. Terraform / OpenTofu

  access_key = "test"
  secret_key = "test"

  skip_credentials_validation = true
  skip_metadata_api_check     = true

  endpoints {
    s3       = "http://localhost:4566"
    sqs      = "http://localhost:4566"
    dynamodb = "http://localhost:4566"
    lambda   = "http://localhost:4566"

    # tambahkan endpoint untuk setiap layanan yang dipakai
  }
}

CDK dan CloudFormation juga didukung: cdk bootstrap dan cdk deploy dengan AWS_ENDPOINT_URL diarahkan ke Floci.

6. Tes otomatis dengan Testcontainers

Pustaka testcontainers-floci tersedia untuk Java, Python, Node.js, Go, dan .NET. Contoh Java (JUnit 5):

<dependency>
  <groupId>io.floci</groupId>
  <artifactId>testcontainers-floci</artifactId>
  <version>2.15.0</version>   <!-- 1.14.0 untuk Testcontainers 1.x / Spring Boot 3 -->
  <scope>test</scope>
</dependency>

@Testcontainers
class S3IntegrationTest {
    @Container
    static FlociContainer floci = new FlociContainer();

    @Test
    void membuatBucket() {
        S3Client s3 = S3Client.builder()
            .endpointOverride(URI.create(floci.getEndpoint()))
            .region(Region.of(floci.getRegion()))
            .credentialsProvider(StaticCredentialsProvider.create(
                AwsBasicCredentials.create(floci.getAccessKey(), floci.getSecretKey())))
            .forcePathStyle(true).build();
        s3.createBucket(b -> b.bucket("bucket-tes"));
        assertThat(s3.listBuckets().buckets()).anyMatch(b -> b.name().equals("bucket-tes"));
    }
}

7. Pindah dari LocalStack

  1. Ganti image: localstack/localstack → floci/floci:latest (atau latest-compat jika init script memanggil aws).
  2. Variabel LocalStack diterjemahkan otomatis: PERSISTENCE=1 → FLOCI_STORAGE_MODE=persistent, LOCALSTACK_HOST → FLOCI_HOSTNAME, LAMBDA_DOCKER_NETWORK, LAMBDA_REMOVE_CONTAINERS, DEBUG=1. Variabel Floci yang di-set eksplisit selalu menang. Matikan dengan LOCALSTACK_PARITY=false.
  3. Init script di /etc/localstack/init/... berjalan tanpa diubah.
  4. Health check /_localstack/health tetap tersedia, dan log mencetak Ready. untuk Testcontainers.

8. Konsol web

Buka http://localhost:4566/_floci/ui. Akses pertama menarik image floci/floci-ui, menyalakannya sebagai sidecar, menunggu health check, lalu mengalihkan browser. Butuh socket Docker. Konsol lain yang mengikuti kontrak konsol (mis. StackPort, Floci Dash) bisa dipakai dengan FLOCI_SERVICES_UI_IMAGE.
