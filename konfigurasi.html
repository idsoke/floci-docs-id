Konfigurasi & Port

Floci dikonfigurasi lewat variabel lingkungan FLOCI_* (ada lebih dari 270). Halaman ini merangkum yang paling sering dipakai. Referensi lengkap ada di docs/configuration/environment-variables.md di repo.

Penjelasan sederhana

Variabel lingkungan itu seperti sakelar dan kenop di panel kontrol. Nama variabel mengikuti struktur konfigurasi: floci.services.lambda.enabled di YAML menjadi FLOCI_SERVICES_LAMBDA_ENABLED (titik dan tanda hubung menjadi garis bawah, huruf besar semua).

Dari mana nilai konfigurasi berasal?

Catatan penting: antarmuka EmulatorConfig boleh punya @WithDefault, tapi application.yml yang menentukan perilaku runtime efektif. Contoh nyata: default Java storage = hybrid, tapi application.yml image = memory.

Contoh docker-compose lengkap

services:
  floci:
    image: floci/floci:latest-compat
    container_name: floci
    ports:
      - "127.0.0.1:4566:4566"          # API AWS
      - "127.0.0.1:7001-7010:7001-7010" # RDS (opsional)
      - "127.0.0.1:6379-6385:6379-6385" # ElastiCache (opsional)
    environment:
      FLOCI_HOSTNAME: floci
      FLOCI_DEFAULT_REGION: ap-southeast-3
      FLOCI_STORAGE_MODE: hybrid
      FLOCI_SERVICES_DOCKER_NETWORK: floci-net
      # FLOCI_SERVICES_IAM_ENFORCEMENT_ENABLED: "true"
    volumes:
      - /var/run/docker.sock:/var/run/docker.sock  # Lambda, RDS, dll.
      - ./floci-data:/app/data                     # data persisten
      - ./init/ready.d:/etc/floci/init/ready.d:ro  # seed otomatis
    networks: [floci-net]

  app:
    build: .
    environment:
      AWS_ENDPOINT_URL: http://floci:4566
      AWS_REGION: ap-southeast-3
      AWS_ACCESS_KEY_ID: test
      AWS_SECRET_ACCESS_KEY: test
    depends_on: [floci]
    networks: [floci-net]

networks:
  floci-net:
    name: floci-net
