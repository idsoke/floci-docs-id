🪣 Modul 1 · S3: Menyimpan File

⏱ 60–90 menit📶 Pemula🧩 Amazon S3 (Simple Storage Service)
Penjelasan sederhana

S3 adalah gudang file tanpa batas, mirip Google Drive tetapi untuk program. Gudangnya disebut bucket, dan setiap file di dalamnya disebut object. Setiap object punya alamat unik bernama key, misalnya gambar/2026/kucing.jpg.

Uniknya, S3 tidak benar-benar punya folder. gambar/2026/ hanyalah bagian awal nama (disebut prefix). Tanda / membuatnya tampak seperti folder.

Tujuan modul

  • Membuat bucket dan memahami aturan namanya.
  • Upload, list, download, dan hapus object.
  • Memahami prefix ("folder palsu") dan metadata.
  • Membuat presigned URL: link sementara untuk berbagi file tanpa kredensial.
  • Membedakan perintah aws s3 (praktis) dan aws s3api (lengkap).

Animasi: upload lalu download

Langkah praktik

Pastikan Floci menyala dan variabel dari Modul 0 sudah diset. Kita pakai nama bucket belajar-idris; ganti sesuka Anda.

Buat bucket

aws s3 mb s3://belajar-idris
aws s3 ls
make_bucket: belajar-idris
2026-11-01 09:00:00 belajar-idris

mb = make bucket. Coba juga aws s3 mb s3://Belajar_Idris: akan ditolak karena huruf besar dan garis bawah tidak diizinkan.

Upload file

echo "Halo dari Floci!" > halo.txt
aws s3 cp halo.txt s3://belajar-idris/
aws s3 ls s3://belajar-idris/
upload: ./halo.txt to s3://belajar-idris/halo.txt
2026-11-01 09:01:10         17 halo.txt

Angka 17 adalah ukuran file dalam byte.

Folder palsu (prefix)

echo "kucing" > kucing.jpg
echo "anjing" > anjing.jpg
aws s3 cp kucing.jpg s3://belajar-idris/gambar/2026/kucing.jpg
aws s3 cp anjing.jpg s3://belajar-idris/gambar/2026/anjing.jpg

aws s3 ls s3://belajar-idris/              # tingkat atas
aws s3 ls s3://belajar-idris/gambar/2026/  # "masuk folder"
aws s3 ls s3://belajar-idris --recursive   # semua object
                           PRE gambar/
2026-11-01 09:01:10         17 halo.txt

2026-11-01 09:02:00          7 anjing.jpg
2026-11-01 09:02:00          7 kucing.jpg

2026-11-01 09:02:00          7 gambar/2026/anjing.jpg
2026-11-01 09:02:00          7 gambar/2026/kucing.jpg
2026-11-01 09:01:10         17 halo.txt

PRE artinya prefix. Folder gambar/ tidak pernah dibuat; ia muncul karena ada key yang diawali gambar/.

Download dan baca isi file

aws s3 cp s3://belajar-idris/halo.txt unduhan.txt
cat unduhan.txt

aws s3 cp s3://belajar-idris/halo.txt -     # "-" = tampilkan langsung ke layar
download: s3://belajar-idris/halo.txt to ./unduhan.txt

Level API: metadata dengan s3api

aws s3 adalah perintah praktis. aws s3api memetakan satu-ke-satu ke operasi API S3 (PutObject, HeadObject, dan seterusnya), sama seperti yang dipanggil SDK di kode Anda.

aws s3api put-object --bucket belajar-idris --key catatan.json \
  --body halo.txt --content-type application/json \
  --metadata pemilik=idris,kategori=latihan

aws s3api head-object --bucket belajar-idris --key catatan.json
import boto3
s3 = boto3.client("s3")

s3.put_object(Bucket="belajar-idris", Key="catatan.json",
              Body=b'{"pesan": "halo"}', ContentType="application/json",
              Metadata={"pemilik": "idris", "kategori": "latihan"})

info = s3.head_object(Bucket="belajar-idris", Key="catatan.json")
print(info["ContentLength"], info["ContentType"], info["Metadata"])

for obj in s3.list_objects_v2(Bucket="belajar-idris")["Contents"]:
    print(obj["Key"], obj["Size"])
{
    "ETag": "\"...\""
}
{
    "LastModified": "...",
    "ContentLength": 17,
    "ETag": "\"...\"",
    "ContentType": "application/json",
    "Metadata": {
        "kategori": "latihan",
        "pemilik": "idris"
    }
}

ETag adalah "sidik jari" isi file (untuk upload biasa berupa MD5). Kalau isinya berubah, ETag berubah.

Presigned URL: link berbagi sementara

Bucket S3 bersifat privat. Untuk memberi akses ke orang lain tanpa memberikan kredensial, buat URL yang sudah ditandatangani dan berlaku sementara.

URL=$(aws s3 presign s3://belajar-idris/halo.txt --expires-in 300)
echo "$URL"
curl -s "$URL"
http://localhost:4566/belajar-idris/halo.txt?X-Amz-Algorithm=AWS4-HMAC-SHA256&X-Amz-Credential=test%2F...&X-Amz-Expires=300&X-Amz-Signature=...
Halo dari Floci!

Bentuk host bisa juga belajar-idris.localhost:4566, tergantung versi CLI; Floci menerima keduanya. Setelah 300 detik, URL itu ditolak.

Sinkronisasi dan bersih-bersih

mkdir -p laporan && echo a > laporan/a.txt && echo b > laporan/b.txt
aws s3 sync laporan s3://belajar-idris/backup/   # hanya mengunggah yang berubah
aws s3 sync laporan s3://belajar-idris/backup/   # jalankan lagi: tidak ada output

aws s3 rm s3://belajar-idris/backup/ --recursive  # hapus semua dengan prefix backup/
aws s3 rb s3://belajar-idris --force              # hapus bucket beserta isinya
upload: laporan/a.txt to s3://belajar-idris/backup/a.txt
upload: laporan/b.txt to s3://belajar-idris/backup/b.txt
delete: s3://belajar-idris/backup/a.txt
delete: s3://belajar-idris/backup/b.txt
...
remove_bucket: belajar-idris

Tanpa --force, rb gagal dengan BucketNotEmpty: bucket harus kosong sebelum dihapus.

Latihan mandiri

Latihan 1. Buat bucket arsip-latihan, upload tiga file ke prefix 2026/11/, lalu tampilkan hanya isi prefix tersebut beserta total ukurannya.
Lihat kunci jawaban 
aws s3 mb s3://arsip-latihan
for i in 1 2 3; do echo "file $i" > f$i.txt; aws s3 cp f$i.txt s3://arsip-latihan/2026/11/; done
aws s3 ls s3://arsip-latihan/2026/11/ --summarize --human-readable

--summarize menambahkan baris Total Objects dan Total Size di akhir.

Latihan 2. Dengan Python, upload file lalu cetak ETag-nya. Ubah isi file, upload lagi, dan bandingkan ETag.
Lihat kunci jawaban 
import boto3
s3 = boto3.client("s3")
for isi in [b"versi satu", b"versi dua"]:
    r = s3.put_object(Bucket="arsip-latihan", Key="v.txt", Body=isi)
    print(r["ETag"])

Dua ETag berbeda karena isinya berbeda. Upload isi yang sama akan menghasilkan ETag yang sama.

Latihan 3. Buat presigned URL yang berlaku 10 detik. Tunggu 15 detik, lalu buka URL-nya dengan curl -i. Status apa yang Anda dapat?
Lihat kunci jawaban

aws s3 presign s3://arsip-latihan/v.txt --expires-in 10, lalu setelah kedaluwarsa responsnya 403 Forbidden dengan kode error AccessDenied ("Request has expired").

Kuis

1. Anda upload laporan/januari.pdf. Apa yang sebenarnya tersimpan di S3?
S3 menyimpan data datar (flat). "Folder" hanyalah tampilan dari prefix key.
2. Cara aman membagikan satu file privat ke teman selama 1 jam?
Presigned URL hanya membuka satu object untuk satu operasi dan kedaluwarsa sendiri.
3. Perintah mana yang paling dekat dengan apa yang dipanggil SDK di kode aplikasi?
s3api memetakan langsung ke operasi API (PutObject), sama dengan s3.put_object() di boto3.

Di AWS asli, apa bedanya?

  • Nama bucket harus unik di seluruh dunia (semua akun AWS). Di Floci cukup unik di laptop Anda.
  • Anda membayar per GB yang disimpan per bulan, per request, dan per data keluar ke internet.
  • Ada storage class (Standard, Infrequent Access, Glacier) untuk menghemat biaya file yang jarang dibuka.
  • Block Public Access aktif secara default. Jangan matikan kecuali benar-benar paham risikonya.
