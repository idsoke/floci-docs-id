Glosarium

Kamus istilah yang dipakai di dokumentasi ini, dengan penjelasan sederhana.

Account ID
Nomor akun AWS 12 digit. Di Floci default-nya 000000000000; access key 12 digit langsung dipakai sebagai account ID.
Action / Operasi
Satu perintah API, mis. CreateBucket, SendMessage, PutItem.
AKID
Access Key ID, bagian publik dari kredensial AWS (mis. AKIA..., ASIA..., atau test di Floci).
ARN
Amazon Resource Name, alamat unik sebuah resource: arn:partisi:layanan:region:akun:resource.
AwsException
Exception di kode Floci yang membawa kode error AWS dan status HTTP; diubah menjadi respons error berformat AWS.
CBOR
Format data biner ringkas (seperti JSON tapi biner). Dipakai protokol Smithy RPC v2 dan file WAL Floci.
CDI
Contexts and Dependency Injection, mekanisme Quarkus untuk membuat dan menyuntikkan objek (@ApplicationScoped, @Inject).
Cold start / Warm start
Cold start: container Lambda harus dibuat dulu (lambat). Warm start: container yang sudah ada dipakai ulang (cepat).
Compat image
Varian image floci/floci:latest-compat yang berisi AWS CLI dan boto3 untuk init hooks.
Control plane / Data plane
Control plane: mengelola resource (buat/hapus tabel). Data plane: memakai resource (baca/tulis item, koneksi database).
Controller / Handler
Lapisan yang mem-parsing request protokol AWS dan membentuk respons. Tidak berisi logika bisnis.
Descriptor
Entri di ResolvedServiceCatalog yang mendeskripsikan satu layanan: kunci, protokol, prefix target, mode storage.
DLQ
Dead-Letter Queue, antrean tempat pesan yang berulang kali gagal diproses dipindahkan.
Drop-in replacement
Pengganti yang bisa langsung dipasang tanpa mengubah konfigurasi lain. Floci terhadap LocalStack.
Emulator
Program yang meniru perilaku sistem lain. Floci meniru AWS.
Endpoint
Alamat tujuan request. Untuk Floci: http://localhost:4566.
ESM (Event Source Mapping)
Konfigurasi Lambda yang menarik data dari SQS/Kinesis/DynamoDB Streams secara otomatis dan memanggil fungsi.
Fan-out
Satu pesan dikirim ke banyak penerima sekaligus (mis. SNS ke beberapa antrean SQS).
Filter (JAX-RS)
Kode yang berjalan sebelum/sesudah controller untuk setiap request, mis. menentukan akun atau memeriksa IAM.
Hybrid storage
Mode penyimpanan: baca/tulis di memori, disalin ke disk secara berkala.
IAM enforcement
Mode opsional Floci yang mengevaluasi kebijakan IAM untuk setiap request (FLOCI_SERVICES_IAM_ENFORCEMENT_ENABLED).
IMDS
Instance Metadata Service (169.254.169.254) yang memberi kredensial dan metadata ke instance EC2. Floci menyediakan servernya.
Init hooks
Skrip yang dijalankan Floci di fase boot/start/ready/stop, mis. untuk membuat resource awal.
JAX-RS
Standar Java untuk membuat API REST (anotasi @Path, @POST, filter, provider). Quarkus memakai RESTEasy Reactive.
JSON 1.0 / 1.1
Protokol AWS: POST / dengan body JSON dan header X-Amz-Target berisi nama operasi.
LocalStack
Emulator AWS lain yang populer. Floci kompatibel dengannya (port, init hooks, endpoint health).
Long polling
Request yang ditahan server sampai ada data atau waktu habis (mis. ReceiveMessage SQS hingga 20 detik).
Multi-account
Isolasi resource per akun: data akun A tidak terlihat oleh akun B.
Native image
Aplikasi Java yang dikompilasi GraalVM menjadi binary mesin: cepat menyala, hemat memori. Image Docker standar Floci memakai ini.
Partisi (partition)
Kelompok region AWS yang terpisah: aws (komersial), aws-cn (Tiongkok), aws-us-gov (GovCloud), ISO, EUSC.
Pre-matching filter
Filter JAX-RS yang berjalan sebelum route dipilih, sehingga boleh mengubah path request.
Presigned URL
URL yang sudah ditandatangani sehingga bisa dipakai tanpa kredensial (mis. untuk unduh/unggah S3).
Protocol claim
Keputusan Floci tentang protokol wire sebuah request, dibuat oleh ProtocolClaimer.
Query protocol
Protokol AWS lama: form-encoded Action=...&Version=..., dibalas XML.
Quarkus
Framework Java untuk aplikasi cloud-native yang menjadi fondasi Floci.
Region
Lokasi geografis AWS, mis. us-east-1, ap-southeast-3 (Jakarta).
Resettable
Antarmuka untuk layanan Floci yang state-nya bisa dikosongkan.
REST JSON / REST XML
Protokol AWS yang memakai method dan path HTTP bermakna; body JSON (Lambda) atau XML (S3).
Runtime API
API HTTP tempat runtime Lambda di container meminta event berikutnya dan mengirim hasil. Floci menyediakannya di port 12000–12499.
SCP
Service Control Policy dari AWS Organizations: batas izin untuk seluruh akun/OU.
Service
(1) Produk AWS seperti S3. (2) Lapisan logika bisnis di kode Floci, mis. SqsService.
Sidecar
Container pendamping yang dinyalakan di samping Floci, mis. konsol web.
SigV4
Signature Version 4, algoritma tanda tangan request AWS (header Authorization: AWS4-HMAC-SHA256 ...).
Smithy
Bahasa model API yang dipakai AWS untuk mendefinisikan layanan dan protokol; dasar semua SDK modern.
StorageFactory
Kelas yang membuat backend storage untuk setiap layanan sesuai mode yang dikonfigurasi.
Testcontainers
Pustaka untuk menyalakan container (mis. Floci) secara otomatis saat menjalankan tes.
Virtual thread
Thread ringan Java 21+ yang murah dibuat; dipakai Floci agar long polling tidak memblokir worker.
Visibility timeout
Waktu sebuah pesan SQS disembunyikan setelah diterima, agar tidak diproses dua konsumen.
WAL
Write-Ahead Log: setiap perubahan dicatat di ujung file log, lalu dirangkum (kompaksi) menjadi snapshot.
Wire protocol
Bentuk data persis yang lewat di jaringan: URL, header, body, kode status.
X-Amz-Target
Header yang menyebut layanan dan operasi untuk protokol JSON, mis. DynamoDB_20120810.PutItem.
