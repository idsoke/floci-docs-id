Katalog Layanan

Semua layanan AWS yang diemulasikan Floci, beserta protokol, jumlah operasi, dan cara kerjanya. Data diambil dari docs/services/index.md (tabel resmi, jumlah operasi persis) dan tabel fitur di README.md.

Cara membaca

Protokol = "bahasa" yang dipakai SDK untuk bicara ke layanan itu (lihat Protokol AWS). Operasi = jumlah perintah API yang didukung. Cara kerja: "Di dalam proses" berarti diemulasikan dengan kode Java di Floci; "Container Docker" berarti Floci menjalankan perangkat lunak asli di container.
