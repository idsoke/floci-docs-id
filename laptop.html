💻 Menjalankan Floci di Laptop

Panduan lengkap dari laptop kosong sampai Floci berjalan setiap hari: kebutuhan sistem, langkah per sistem operasi, Docker Compose, menyimpan data, update, dan cara mengatasi masalah.

Penjelasan sederhana

Floci dikemas sebagai container Docker, semacam "kotak bekal" yang sudah berisi semua yang dibutuhkan program. Anda cukup memasang Docker (lemari tempat kotak bekal disimpan dan dipanaskan), lalu menyuruh Docker menjalankan kotak Floci. Tidak perlu memasang Java, database, atau apa pun lainnya.

Setelah menyala, Floci "membuka loket" di alamat http://localhost:4566. Semua program di laptop Anda, seperti AWS CLI, kode Python, atau Terraform, tinggal diarahkan ke alamat itu.

Langkah 1: Pasang Docker dan AWS CLI

  1. Aktifkan WSL2. Buka PowerShell sebagai Administrator, jalankan perintah di bawah, lalu restart laptop. Setelah restart, jendela Ubuntu terbuka; buat username dan password Linux. 
    wsl --install -d Ubuntu
  2. Pasang Docker Desktop dari docker.com. Saat instalasi, centang Use WSL 2 instead of Hyper-V.
  3. Buka Docker Desktop → Settings → Resources → WSL integration → aktifkan untuk Ubuntu → Apply & restart.
  4. Buka terminal Ubuntu (dari Start menu atau Windows Terminal). Mulai sekarang semua perintah dijalankan di sini: 
    docker version            # bagian "Server" harus muncul
sudo apt update && sudo apt install -y unzip python3-venv
curl "https://awscli.amazonaws.com/awscli-exe-linux-x86_64.zip" -o awscliv2.zip
unzip -q awscliv2.zip && sudo ./aws/install
aws --version
Kenapa WSL? Docker di Windows sebenarnya berjalan di dalam Linux kecil (WSL2). Bekerja langsung di terminal Ubuntu membuat perintah di dokumentasi ini bisa dipakai apa adanya, dan akses file jauh lebih cepat. Simpan proyek di folder Linux (~/proyek), bukan di /mnt/c/....
  1. Pasang salah satu: Docker Desktop (docker.com), OrbStack (lebih ringan), atau Colima (gratis, lewat Homebrew). Ketiganya menyediakan perintah docker.
  2. Pasang AWS CLI dan cek: 
    # dengan Homebrew
brew install awscli
# atau installer resmi
curl "https://awscli.amazonaws.com/AWSCLIV2.pkg" -o AWSCLIV2.pkg && sudo installer -pkg AWSCLIV2.pkg -target /

docker version
aws --version
  3. Colima saja: nyalakan dulu dengan colima start --cpu 4 --memory 6.

Di Apple Silicon, Floci dan fungsi Lambda otomatis memakai image ARM64, jadi tidak ada emulasi yang lambat.

# Docker Engine (skrip resmi Docker)
curl -fsSL https://get.docker.com | sudo sh
sudo usermod -aG docker $USER       # agar tidak perlu sudo; logout lalu login lagi
docker version

# AWS CLI v2 (ganti x86_64 dengan aarch64 untuk ARM)
curl "https://awscli.amazonaws.com/awscli-exe-linux-x86_64.zip" -o awscliv2.zip
unzip -q awscliv2.zip && sudo ./aws/install
aws --version

Docker Desktop for Linux juga bisa dipakai, tetapi Docker Engine biasa lebih ringan.

Langkah 2: Jalankan Floci

Buat folder kerja dan file compose.yaml:

mkdir -p ~/floci && cd ~/floci
cat > compose.yaml <<'EOF'
services:
  floci:
    image: floci/floci:latest
    container_name: floci
    ports:
      - "127.0.0.1:4566:4566"          # hanya bisa diakses dari laptop ini
    volumes:
      - /var/run/docker.sock:/var/run/docker.sock   # untuk Lambda, RDS, dll.
      - floci-data:/app/data                         # tempat data disimpan
    user: root                         # agar boleh memakai docker.sock
    environment:
      FLOCI_STORAGE_MODE: hybrid       # data tetap ada setelah restart
      FLOCI_STORAGE_PERSISTENT_PATH: /app/data
    restart: unless-stopped            # ikut menyala saat Docker menyala

volumes:
  floci-data:
EOF

docker compose up -d
docker compose logs -f floci         # Ctrl+C untuk berhenti melihat log
[+] Running 2/2
 ✔ Volume "floci_floci-data"  Created
 ✔ Container floci            Started
…
IAM:       policy enforcement disabled (…)
Ready.
Kenapa tanpa FLOCI_HOSTNAME? Contoh Compose di dokumentasi resmi memakai FLOCI_HOSTNAME: floci. Itu berguna jika aplikasi Anda juga berjalan sebagai service di Compose yang sama. Efek sampingnya, alamat antrean SQS dikembalikan sebagai http://floci:4566/…, yang tidak bisa dibuka dari terminal laptop. Untuk belajar dan memakai CLI di laptop, biarkan setelan itu kosong.
docker run -d --name floci \
  -p 127.0.0.1:4566:4566 \
  -v /var/run/docker.sock:/var/run/docker.sock -u root \
  -v floci-data:/app/data \
  -e FLOCI_STORAGE_MODE=hybrid -e FLOCI_STORAGE_PERSISTENT_PATH=/app/data \
  --restart unless-stopped \
  floci/floci:latest

Versi paling sederhana (data hilang saat container dihapus, Lambda tidak tersedia): docker run --rm -p 4566:4566 floci/floci:latest.

Jika halaman Releases menyertakan file floci-aws-<os>-<arch>, Floci bisa dijalankan tanpa Docker:

VERSION=x.y.z                       # versi rilis yang memuat binary
ASSET=floci-aws-linux-amd64         # darwin-arm64 untuk Mac M-series, windows-amd64.exe untuk Windows
curl -fsSLO "https://github.com/floci-io/floci/releases/download/$VERSION/$ASSET"
install -m 755 "$ASSET" ~/.local/bin/floci-aws
FLOCI_STORAGE_MODE=persistent floci-aws

Binary mendengarkan di 127.0.0.1:4566. Data persisten disimpan di ~/.local/share/floci-aws (Linux), ~/Library/Application Support/floci-aws (macOS), atau %LOCALAPPDATA%\floci-aws (Windows). Tanpa Docker, layanan berbasis container (Lambda, ECS, RDS, ElastiCache, dll.) tidak bisa menjalankan container. Kalau rilis yang Anda pilih tidak memuat binary, pakai cara A atau B.

# butuh Java 25+ dan Maven 3.9+
git clone https://github.com/floci-io/floci.git
cd floci
./mvnw quarkus:dev                   # mode pengembangan dengan hot reload di port 4566

# atau build JAR lalu jalankan
./mvnw clean package -DskipTests
java -jar target/quarkus-app/quarkus-run.jar

Lihat Panduan Kontributor untuk alur pengembangan lengkap.

Langkah 3: Hubungkan AWS CLI dan cek

cat >> ~/.bashrc <<'EOF'
# --- Floci ---
export AWS_ENDPOINT_URL=http://localhost:4566
export AWS_DEFAULT_REGION=us-east-1
export AWS_ACCESS_KEY_ID=test
export AWS_SECRET_ACCESS_KEY=test
EOF
source ~/.bashrc

curl -s http://localhost:4566/_floci/health | head -c 200; echo
aws sts get-caller-identity
aws s3 mb s3://tes-laptop && aws s3 ls
{"services":{"s3":"running", … },"edition":"community","version":"…"}
{
    "UserId": "000000000000",
    "Account": "000000000000",
    "Arn": "arn:aws:iam::000000000000:root"
}
make_bucket: tes-laptop
2026-11-01 10:00:00 tes-laptop

Di macOS dengan zsh, tulis ke ~/.zshrc. Di PowerShell, lihat tab PowerShell di Modul 0.

Konsol web: buka http://localhost:4566/_floci/ui di browser untuk melihat bucket, antrean, dan tabel secara visual. Pembukaan pertama mengunduh dan menyalakan container konsol, jadi tunggu sebentar. Fitur ini membutuhkan docker.sock.

Menyimpan data: pilih mode storage

FLOCI_STORAGE_MODEData setelah restartKapan dipakai
memory (default image)❌ HilangTes otomatis, latihan yang ingin selalu mulai bersih
hybrid ⭐✅ Ada (disalin ke disk berkala)Pemakaian sehari-hari di laptop
persistent✅ Ada (ditulis langsung ke disk)Tidak boleh kehilangan perubahan terakhir
wal✅ Ada (log + snapshot)Banyak penulisan, ingin aman dan cepat

Data disimpan di volume Docker floci-data. Selama volume itu tidak dihapus, data tetap ada walau container dibuat ulang. Detail cara kerjanya ada di halaman Penyimpanan Data.

Pemakaian sehari-hari

TujuanDocker Compose (di folder ~/floci)docker run
Menyalakandocker compose up -ddocker start floci
Mematikan (data aman)docker compose stopdocker stop floci
Statusdocker compose psdocker ps
Melihat logdocker compose logs -fdocker logs -f floci
Update ke versi terbarudocker compose pull && docker compose up -ddocker pull floci/floci:latest, lalu hapus dan jalankan ulang container
Hapus container (data aman)docker compose downdocker rm -f floci
Reset total (data hilang)docker compose down -vdocker rm -f floci && docker volume rm floci-data
  • Menyala otomatis saat laptop dinyalakan: restart: unless-stopped sudah diset. Aktifkan juga Docker Desktop → Settings → General → Start Docker Desktop when you sign in.
  • Membersihkan container Lambda yang tertinggal setelah banyak latihan: docker ps -a, lalu docker container prune.
  • Membebaskan disk dari image lama: docker image prune (aman) atau docker system prune (lebih agresif).
  • Mengunci versi agar tidak berubah tiba-tiba: ganti floci/floci:latest dengan nomor versi, misalnya floci/floci:2.4.0.

Hemat RAM di Windows (WSL2)

WSL2 bisa memakai hingga setengah RAM laptop. Batasi lewat file C:\Users\<nama>\.wslconfig:

[wsl2]
memory=6GB
processors=4
swap=4GB

Lalu jalankan wsl --shutdown di PowerShell dan buka lagi Docker Desktop. Di macOS, atur batas RAM di pengaturan Docker Desktop/OrbStack, atau lewat colima start --memory 6.

Membuka situs dokumentasi ini secara offline

Seluruh dokumentasi ini adalah file HTML biasa tanpa server.

git clone https://github.com/idsoke/floci-docs-id.git
cd floci-docs-id

Checklist: siap dipakai

  • docker version menampilkan bagian Client dan Server.
  • docker compose ps menampilkan floci berstatus running.
  • aws sts get-caller-identity menampilkan akun 000000000000.
  • Bucket yang dibuat masih ada setelah docker compose restart (mode hybrid).
Langkah berikutnya: mulai kursus Belajar AWS dari Nol, atau lihat Cara Memakai untuk contoh SDK, Terraform, dan Testcontainers.
